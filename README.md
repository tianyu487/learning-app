# 小科学家 · 学习App

纯静态网页，无需构建，直接用浏览器打开即可。

## 入口

`学习App/小科学家_网络星图版.html` —— 主页面（成长星图·网络版）

## 目录结构

```
学习App/
  小科学家_网络星图版.html   主页面
  chem_courses.js            81 门化学课程 + 选择题测评数据（GRAPH_COURSES）
  chem_network.js            成长星图结构：8 分支 · 62 主题 · 324 知识点 + 8 条主线（CHEM_NETWORK）
  chem_edges.js              知识点先修依赖 / 表征关联边（CHEM_EDGES）
  chem_illust.js             课程演示图与知识点原理图 SVG（ILLUST）
化学项目库/                  化学项目（HX-L1 ~ HX-L6），每个项目含：
  <项目>/项目导师/            项目卡片、习题、图谱KP
  <项目>/产品供应链/          产品交接
  <项目>/视频宣发/            宣发交接
  <项目>/学员端/              闯关任务卡、记录卡（目前仅 HX-L1-001）
读经典项目库/                读经典项目（DJ-L3-001）
project制作/                 内容制作资料
  项目结构表_使用说明.md       项目编号规则、字段字典、0–10 阶骨架
  项目总表.csv                项目总表模板（含示例行）
  生成600项目.py              生成 600 项目总表（运行后输出 项目总表_600.csv / .xlsx，依赖 openpyxl）
  项目方案_HX-02-002_*.md 等   HX-02-002「看不见的二氧化碳」方案、分镜脚本、配套书第 1 课、学生学习包
  化学知识图谱_viewer.html     化学知识图谱演示 viewer（数据内嵌）
```

注：`project制作/` 里的 HX-02-002 用的是早期编号规则（学科-阶级-序号），与 `化学项目库/` 的 HX-L1-001 规则不同。

主页面通过相对路径 `../化学项目库/...`、`../读经典项目库/...` 链接到项目卡片和习题，
所以三个文件夹需要保持同级。

## 说明

- `chem_*.js` 由数据源（chemistry_graph.json / chemistry_data.js）自动生成，修改数据时注意同步。
- 学习进度保存在浏览器本地，可在页面中导出 / 导入 JSON 备份。
