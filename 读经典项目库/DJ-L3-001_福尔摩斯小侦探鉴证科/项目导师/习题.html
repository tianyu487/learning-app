A · 本阶题层析破案 · 控制变量 · 证据链
1把一支黑色水笔点在滤纸上、滴水后跑出蓝、紫、粉几条带。这说明黑墨水是?A 一种纯颜色 / B 多种颜色的混合物 本阶易可判分
思考方法:能被分成好几条不同颜色的带,说明里面本来就混着好几种色素。 答:B
2几支嫌疑笔比对时,为什么要点在"同一张纸、同一条起跑线、用同样的水"上? 本阶中人工判
思考方法:要"公平":只让"笔不一样"这一项不同,纸、水、起点全固定——这就是控制变量,图谱才能横比。 参考:固定纸、水、起跑线,几支笔的图谱才可比;否则色带跑得高低不同,分不清是笔的差别还是条件的差别。
3现场墨跑出"蓝+粉";1 号笔"只蓝",2 号"蓝+黄",3 号"蓝+粉"。凶器最可能是哪支?请写出你怎么排除另外两支。 本阶中人工判
思考方法:证据链 = 比组合 + 排除。现场有粉,1 号没粉先排除;2 号多个黄、现场没黄也排除;只剩 3 号"蓝+粉"完全对上。 答:3 号。1 号无粉、2 号有黄(现场没黄),都与现场组合不符被排除,3 号"蓝+粉"与现场一致。
4起跑线为什么要用"铅笔"画,而不是用墨水笔画? 本阶中人工判
思考方法:想想哪种线"不会跟着水跑"。铅笔是石墨,不溶于水、不会被水带着爬,图谱才不会被弄乱。 参考:铅笔(石墨)不溶于水、不会随水上爬,不会污染色带;墨水线会自己跑开,干扰判读。
B · 初中考点混合物分离 · 物质检验 · 逻辑谬误
5下列属于"分离/提纯混合物"的方法的是(多选)?A 过滤 / B 纸层析(色谱) / C 蒸发结晶 / D 燃烧 初中中可判分
思考方法:分离是"把混在一起的东西分开、成分不变";燃烧会生成新物质,不是分离。 答:A、B、C(燃烧 D 不是分离)。
6层析能把墨水里不同色素分开,主要是因为这些色素?A 颜色不同 / B 随水在纸上"跑"的快慢不同 / C 质量都相等 初中中可判分
思考方法:有的色素更"亲水"跑得快、爬得高,有的更"恋纸"跑得慢,快慢不同就分到了不同高度。 答:B
7【推理】"凶手一定用蓝墨水。这支笔是蓝墨水,所以凶手就是用这支笔的人。"这个推理可靠吗?为什么? 初中难人工判
思考方法:"用蓝墨水"的笔不止这一支。从"凶手用蓝墨水"推不出"就是这支蓝笔"——这是以偏概全/范围放大。 参考:不可靠。蓝墨水的笔有很多支,符合"蓝墨水"只是必要条件、不是唯一证据;还需层析组合、其它物证才能锁定。
8【实验探究】要确认两份墨迹是不是"同一支笔"写的,你怎么用纸层析做"同一认定"?写出做法和判据。 初中中人工判
思考方法:同条件下做两份的层析,比色带的"颜色种类 + 高低位置"是否完全一致。 参考:把两份墨在同纸、同水、同起跑线点样层析;若色带的颜色组合与各自高度都完全一致,则支持"同一支笔";有一条对不上即可否定。
C · 高中考点比移值 Rf · 充分/必要条件 · 三段论
9比移值 Rf = 色斑移动距离 ÷ 溶剂前沿移动距离。某色斑移动 3.0 cm,溶剂前沿移动 12.0 cm,求 Rf。 高中中可判分
思考方法:直接代入 Rf=色斑距离÷前沿距离,结果是 0~1 之间的小数。 答:Rf = 3.0 / 12.0 = 0.25。
10同一条件下,某成分的 Rf 只与它本身(及纸、溶剂)有关。两份样品里各有一条色带 Rf 都 = 0.25,能否就此断定"是同一种物质"?还需补什么证据? 高中难人工判
思考方法:Rf 相同是"同一物质"的必要不充分条件——不同物质可能凑巧 Rf 相近。要多条带都一致、或换一种溶剂体系再验。 参考:不能。Rf 相同只是必要条件,可能是巧合;需比对全部色带是否都一致,并换不同展开剂(溶剂)再测,多重一致才更可信。
11用"充分条件 / 必要条件"分析:"是同一支笔"与"层析图谱完全相同"是什么关系?图谱相同能必然推出同一支笔吗? 高中难人工判
思考方法:同一支笔 → 图谱必然相同(必要条件成立);但反过来,图谱相同不一定同一支笔(同款墨水的两支笔也会相同)。 参考:"图谱相同"是"同一支笔"的必要条件、不是充分条件。图谱相同推不出必然同一支笔(可能是同款墨水的不同笔);要锁定还需更多独立证据。
12【三段论】大前提:"凡用 3 号墨写的字,层析都含蓝+粉";小前提:"现场字迹层析含蓝+粉"。能否必然推出"现场字迹是 3 号墨"?这属于哪种逻辑情形? 高中难人工判
思考方法:由"3号→含蓝粉"和"现场含蓝粉",想推回"现场是3号",是"肯定后件"——逻辑上不成立(别的墨也可能含蓝粉)。 答:不能必然推出。这是"肯定后件"谬误:含蓝+粉的不一定只有3号墨,只能说现场"可能"是3号、需排除其它含蓝粉的来源。
