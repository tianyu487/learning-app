书 · 轻物料 · 履约
📖 产品主体 = 书,不是物料盒子。本线初期主营配套书《小侦探鉴证科 · 办案手册》(经典《福尔摩斯》导读 + 鉴证原理图解 + 一季案件任务卡),物料只是几块钱的轻物料包(滤纸 + 彩笔 + 滴管),甚至可让家庭自备。毛利与复购都在书与内容:整季订阅、下一阶续订;物料近乎赠品 / 低成本选配,履约极轻。

1书与内容(可复购主体)

产品说明
《小侦探鉴证科 · 办案手册》经典《福尔摩斯》选段导读 + 纸层析/证据链原理图解 + 5~8 桩案件任务卡(含本卡片的五拍流程)。核心售卖品。
侦探季订阅一季多案、按阶递进;配每日"思辨小案"短内容,养留存。
家长共读页每案附"和孩子一起推理"的提问清单(费曼 + 亲子思辨)。

2轻物料包 BOM(成本极低 / 可自备)

滤纸条 / 咖啡滤纸(分切好)
水性彩笔 / 马克笔 ×3~4(嫌疑笔,刻意不同墨)
一次性滴管 / 小透明杯
铅笔(画起跑线用)
办案记录卡 + 案件信封
(选学)柠檬汁密写小料包
家庭多半已有彩笔、铅笔、杯子;盒内只需备好"分切滤纸 + 几支墨水刻意不同的笔 + 记录卡"即可,也可做成纯数字版让家长自备。
关键质控:嫌疑笔必须是"水性墨水"、且几支墨水成分刻意不同。油性 / 中性签字笔不溶于水,在滤纸上"跑不开",项目直接失败;且几支笔若墨水太像,层析图谱区分不出,破不了案。选笔是本项目成败点——建议盒内固定配几支已验证"能跑开、组合明显不同"的水性笔,并在任务卡注明"用盒内笔或家里的水彩笔,别用油性签字笔"。

3电子元器件清单

项说明
基础包无电子元件。本线主营书 + 轻物料,保持低成本、易履约。
跨线衔接学有余力可接化学项目库第 3 阶起的 micro:bit 线(如把层析升级成数字比色),但不入本包。

4安全与履约

安全:水性墨水、滤纸均无毒,但实验墨水不入口;柠檬汁密写若用蜡烛/灯泡显影需成人操作防烫;剪滤纸用安全剪刀、成人协助。整体为低风险纸笔类活动。
项建议
履约书为主、按季发货 / 数字交付;轻物料随书附寄或让家长自备,大幅降低物流与库存。
开箱即玩随书附五拍任务卡 + 案件信封,与导师/教研口径一致,拆开即可"接案"。
合规儿童读物出版合规;水性墨水/文具符合儿童文具安全标准。
