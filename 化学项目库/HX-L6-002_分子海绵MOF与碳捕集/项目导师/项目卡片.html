★点亮 KP（取自化学知识图谱）

锚定真实图谱节点（E/H/C/A 分支）。绿=认识，紫=方法。本阶达到"读懂前沿信息并解释、迁移到碳捕集"。
认识KP1 配位键（E9 / A3）
金属离子提供空轨道、配体上的孤对电子配位上去——配位键是"共用电子对由一方提供"的特殊共价键。
认识KP2 多孔与比表面积·吸附（C5/G）
内部布满纳米孔道→比表面积极大→吸附位点多→单位质量吸附量大。
方法KP3 物理吸附 vs 化学吸附
物理吸附作用弱、放热少、易脱附再生；化学吸附强、常需较高温脱附。MOF 抓 CO₂ 以物理吸附为主，故易循环。
认识KP4 自组装·超分子（H4）
"节点 + 连接杆"像搭积木自组装成周期性三维网络；改金属或配体即可定制孔径——可设计性是 MOF 的灵魂。
移入"上不封顶"：晶胞与配位数计算（A6）、配合物组成与命名（E9）、碳中和工业与绿色化学（H7）、催化不改变 ΔH/K（C5）——见习题高中档。

★开放决策点

挑战：自己设计一个"多孔抓取力"对比实验，并预测 MOF 会怎样。
学员自选：用哪些材料比吸附（变色硅胶 / 活性炭 / 棉花 / 沙子）｜ 比吸水还是比吸色/吸味 ｜ 怎么定量（称重 / 比色），并思辨"如果把 MOF 的孔径调大或调小、换一种金属节点，会怎样？"（呼应 MOF 的可设计性）。

六件套 · 教学内容核

① 驱动问题

"2025 年诺贝尔化学奖颁给了'分子海绵'MOF——一克材料铺开接近一个足球场，能从沙漠空气里抓水、从烟道气里抓 CO₂。它凭什么这么能'抓'？我们能不能用身边的多孔材料，亲手称出这种抓取的力量，再读懂这项诺奖背后的化学？"

② 探究脉络

1
好奇钩子KP2 预告
亮出 2025 诺奖新闻；把一小包变色硅胶丢进潮湿罐子 → 蓝色慢慢变粉（悄悄吸饱了水）。"一小勺粉末，凭什么吸这么多？"
反直觉 + 诺奖权威，抓注意力。
2
先动手试错KP2 缺口
等质量的棉花 / 沙子 vs 活性炭 / 硅胶，放同样潮湿环境，称吸水前后质量 → 多孔的猛得多。"明明都不大，凭什么差这么多？"
制造"看不见的内部"的缺口。
3
玩中探究KP2KP4
引入比表面积——多孔=内部布满纳米孔道，一克铺开近一个足球场；再引入 MOF=金属节点+有机连接杆靠配位键自组装成的可设计多孔晶体。
在最想知道答案时引入配位 + 自组装 + 比表面积。
4
回现实检验KP3KP1
用吸附做点真事：活性炭除色 / 除味；把吸饱水的硅胶加热脱附又变蓝、能重复用（→ 物理吸附、可再生）。联系 MOF 抓 CO₂ → 碳中和。
定量 + 可逆 = 真实检验，现实当裁判。
5
点亮+费曼全部
点亮 KP1–4；让学员讲："MOF 为什么能抓 CO₂、又容易放出来再用？为什么说它'可以设计'？这和碳中和有什么关系？"
能把一道诺奖信息题讲明白，才算学会。

③ 证据

类型内容
对比证据等质量的多孔材料（活性炭/硅胶）比致密材料（沙/棉）吸水、吸色多得多 → 吸附靠的是多孔（比表面积）。
定量证据称吸附前后质量差 / 比色前后深浅 → 把"抓取力"变成可比的数。
可逆证据吸饱的硅胶加热又变蓝、能重复用 → 物理吸附作用弱、可脱附再生（呼应 MOF 易循环）。
可设计证据（信息）改金属节点或有机配体即可定制孔径与亲和性 → MOF 的"可设计性"，与普通多孔材料的关键区别。

④ 评价

  • 能说出：配位键是共用电子对由一方提供的特殊共价键；MOF 靠它把"节点+连接杆"自组装成多孔网络。
  • 能解释：为什么多孔 / 比表面积大就吸得多；物理吸附与化学吸附的差别。
  • 能迁移：把"多孔吸附"迁移到 MOF 捕集 CO₂ → 碳中和。
  • L4 挑战者达标：能独立读懂一道 MOF / 钙电池 / PFAS 等前沿信息给予题并讲清推理（费曼）。
  • 导师端三轴记录：点亮 KP 数 / 对照实验是否真由学员设计 / 能否独立讲清前沿信息题。

⑤ 分步解答

  1. 演示：变色硅胶放进潮湿密封罐，观察由蓝变粉（吸水）。
  2. 对比：等质量活性炭 / 硅胶 vs 棉花 / 沙子，同样潮湿环境放同样时间，电子秤称吸水前后质量差。
  3. 除色 / 除味：把活性炭放进有色或有味的水里，看颜色变浅、味道变淡。
  4. 再生：把吸饱水的硅胶加热烘干→ 又变蓝，能重复用（物理吸附、可脱附）。
  5. 读诺奖资料卡：MOF=金属节点+有机连接杆靠配位键自组装、多孔、可设计、抓 CO₂。
  6. 做一道信息给予计算题（如：4.4 mmol/g 的 MOF，1 g 最多吸 CO₂ 多少克）。
  7. 记录卡：写"多孔为什么吸得多 / MOF 如何帮碳中和 / 它和活性炭的关键区别"。
