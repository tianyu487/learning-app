习题
12 题 · 每题含思考方法本阶 → 初中 → 高中
交接 → 项目导师
分档可裁剪使用
标签:绿=本阶(小学高年级)、蓝=初中考点、紫=高中考点;后附难度与是否可判分。进阶题用于"上不封顶",按学员水平选用。
A · 本阶题半定量 · 控制变量
1同样多的蓝色碘液,A 果汁滴 8 滴褪色、B 果汁滴 20 滴褪色,哪个维C更高? 本阶易可判分
思考方法:碘量固定时,用的果汁越少就越"浓"——用量与含量成反比。 答:A
2要"公平"比较两种果汁的维C,下列哪些必须保持一样?碘液量 / 淀粉量 / 滴管 / 室温 / 果汁种类 本阶中人工判
思考方法:控制变量——只让"果汁种类"这一个不同,其余全部固定。 答:碘液量、淀粉量、滴管、室温都要一样;只有果汁种类不同。
3滴定时为什么要"逐滴加、边加边晃,到刚好褪色就停",而不是一次倒一大股? 本阶中人工判
思考方法:终点是"刚好褪色"的那一刻;一次倒多了会过量,数出来的滴数不准。 答:逐滴才能抓住刚好褪色的终点,倒多了会过量、读数偏大。
B · 初中考点氧化还原概念 · 物质检验 · 实验探究
4淀粉遇碘变蓝,这一现象可用来检验?A 淀粉(或碘)的存在 B 维生素C C 食盐 初中中可判分
思考方法:特征显色 = "指纹";蓝色对应淀粉与碘,可互相检验。 答:A
5维C 能使碘的蓝色褪去,说明维生素C具有?A 酸性 B 还原性 C 碱性 初中中可判分
思考方法:它把碘"夺色"、使碘转化为无色 → 维C 把碘还原,体现还原性。 答:B
6下列说法正确的是?A 滴数越多维C越高 B 碘把维C氧化、维C把碘还原 C 蓝色是维C本身的颜色 初中中可判分
思考方法:滴数越多反而维C越低;蓝色来自碘-淀粉;一方被氧化必有另一方被还原。 答:B
7【实验探究】小明猜"加热会破坏果汁里的维C"。请你帮他设计一个实验来验证,写出做法与对照。 初中中人工判
思考方法:控制变量——取同一果汁分成两份,一份加热、一份不加热,其余条件全相同,分别测使蓝色褪去的滴数对比。 答:同一果汁分两份,A 份加热数分钟后冷却、B 份不加热;用相同碘液量、相同滴管分别滴定,比较所需滴数。若加热份所需滴数明显增多,说明维C被破坏。
C · 高中考点氧化剂还原剂 · 电子转移 · 滴定与定量
8反应 C₆H₈O₆ + I₂ → C₆H₆O₆ + 2HI 中,氧化剂与还原剂分别是? 高中中可判分
思考方法:化合价升高、被氧化的是还原剂;化合价降低、被还原的是氧化剂。维C 失氢被氧化,碘得电子被还原。 答:氧化剂是 I₂,还原剂是维生素C(C₆H₈O₆)。
9上式中碘元素化合价怎样变化?每 1 mol I₂ 参加反应转移多少电子? 高中中可判分
思考方法:I 由 0 → −1(每个碘原子得 1 个电子),一个 I₂ 含 2 个碘原子。 答:碘从 0 价降到 −1 价;每 1 mol I₂ 转移 2 mol 电子。
10用已知浓度的碘标准液滴定维C溶液、以淀粉作指示剂。滴定终点的现象是什么?为什么"出现蓝色"即为终点? 高中难人工判
思考方法:维C 没反应完时,加进去的碘立刻被还原、不显蓝;维C 一旦耗尽,多滴的碘遇淀粉显蓝。 答:当滴入最后一滴碘液时,溶液变蓝且半分钟内不褪色,即为终点——说明维C 恰好被碘完全氧化。
11【计算】维C与 I₂ 按物质的量 1:1 反应。滴定恰好用去 0.010 mol/L 碘液 20.0 mL,求被测维C的物质的量。 高中难可判分
思考方法:n(I₂)=c·V,体积换算成升;按 1:1 得 n(维C)=n(I₂)。 答:n(I₂)=0.010×0.0200=2.0×10⁻⁴ mol;故 n(维C)=2.0×10⁻⁴ mol。
12承上题,已知维C摩尔质量 M=176 g/mol,求该样品中维C的质量(mg)。 高中难可判分
思考方法:m=n·M,再把克换算成毫克。 答:m=2.0×10⁻⁴×176≈0.0352 g ≈ 35.2 mg。
