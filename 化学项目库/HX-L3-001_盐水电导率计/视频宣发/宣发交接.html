1知识反转一句话

"我家小孩用两根线和一块小板,自己做了台测水的仪器——纯水读 0,撒把盐数字飙起来。导电的不是水,是水里会动的离子。" 反转点:看着像高级实验室设备 → 其实是孩子手搓的、原理就是"离子搬电"

23 秒钩子

  • 首选:探头插纯水屏显 0 → 撒盐搅拌 → 数字"哗"地飙高,LED 条满格。
  • 备选:四杯"看起来一样"的水,仪器一测,读数天差地别。
  • 话题:这水到底有多咸 / 喝的水真的"纯净"吗?(自来水 vs 矿泉水 vs 纯净水)

3关键字幕条

两根线 + 一块板 = 测水仪器纯水不导电糖水也不导电 导电靠离子越咸数字越大画条曲线猜浓度micro:bit 首次登场

4可视化素材源

素材拍摄要点
读数飙升特写固定机位拍屏幕/LED 条,从 0 到满格;撒盐动作与数字跳动同框。
三杯对比并排纯水/糖水/盐水同框,各自读数贴在杯前,突出"看着一样、读数不同"。
浓度—读数曲线动画几个点逐个落位连成线,再用未知点反查浓度,做"猜中"反转。
接线特写微距拍鳄鱼夹接 P1/3V、电极入水——强调"孩子自己接的"。
