⚡ 电子核心首秀:这是化学阶梯里 micro:bit 第一次进盒。它只做一件最简单的事——读两根电极间的电流大小、变成屏上的数字。一块板从这阶起,第 4–6 阶反复复用,正是手册"一块电子大脑跑几十个盒子"的落点。

★点亮 KP

本阶 4 个 KP 从定性走向"半定量 + 建模 + 传感",掌握到"能解释离子导电、能画浓度—读数曲线、能说清为什么要校准"。
认识KP1 电解质·离子导电
盐溶进水里变成会动的离子,电才通得过;纯水、糖水几乎不导电。
半定量KP2 电导随浓度变化
盐越多,导电越强,屏上读数越大——浓度可被"读出来"。
方法KP3 传感建模启蒙
用电路当"传感器",把看不见的导电变成数字,再连成一条曲线。
方法KP4 校准与零点
先用纯水定"零"、已知盐水定"标",不同杯子的读数才可比。
移入"上不封顶"、本阶不点亮:离子浓度计算、电阻率/电阻、欧姆定律、强弱电解质,留给初中—高中(见习题进阶题)。

★开放决策点

挑战:做一把自己的"咸度尺",猜中一杯未知盐水。
孩子自选探究方向:测哪些水(自来水/矿泉水/糖水/不同浓度盐水) ｜ 电极插多深 ｜ 用几个浓度点定标。 要求:先猜 → 再测 → 画"浓度—读数"曲线,并说清"我固定了什么、怎么归零"。

六件套 · 教学内容核

① 驱动问题

"纯水几乎不导电,撒一把盐就通了电。能不能自己做一台仪器,让一杯水的'咸淡'变成屏幕上能读的数字,再用它猜出一杯神秘水有多咸?"

② 探究脉络

1
好奇钩子KP1 预告
两根线接 micro:bit 插进纯水 → 屏上数字≈0;撒一勺盐搅开 → 数字"噌"地跳起来。
反直觉:水看着一样,数字却差很多,3 秒抓注意力。
2
先动手试错KP1 缺口
先测纯水、再测糖水 → 都几乎不导电。"糖也化进水里了,凭什么糖水不导电、盐水导电?"
制造"咦,为什么"的缺口,逼出对"离子"的需求。
3
玩中探究KP1KP2
引入:盐在水里拆成会动的离子→能带电;糖不拆成离子→不导电。配 1/2/3 勺盐水,读数一阶阶升高。
在最想知道答案时引入离子导电 + 浓度越高读数越大。
4
回现实检验KP3KP4
先校准(纯水归零、已知盐水定标),把几个浓度点画成"浓度—读数"曲线;再测一杯未知盐水,用曲线反推它有多咸。
用自造曲线预测未知,误差当裁判——现实说了算。
5
点亮+费曼全部
点亮 KP1–4;让孩子讲"为什么盐水导电、糖水不导电?屏上的数字到底代表什么?为什么测之前要先归零?"
讲明白才算学会。

③ 证据

类型内容
对比证据纯水/糖水读数≈0、盐水读数高 → 导电靠的是离子,不是"湿"或"甜"。
单调证据盐量逐级增加,读数随之逐级升高 → 电导随浓度变化,可用来"量"浓度。
校准证据同一台仪器先归零、再用已知盐水定标,不同杯子的读数才能放在一起比。
建模证据把"浓度—读数"几个点连成一条线,就能预测曲线上没测过的未知点。

④ 评价

  • 能说出:盐溶解会拆出离子才导电;糖水不导电是因为糖不拆成离子。
  • 能说出:盐越多读数越大;能把几个点画成浓度—读数曲线。
  • 能解释:测前为什么要归零/校准,电极插多深要固定。
  • L3 萌芽:能用自制曲线预测一杯未知盐水的浓度,并讲清仪器原理(费曼)。
  • 导师端三轴记录:点亮 KP 数 / 开放决策是否真由孩子定 / 能否独立讲解建模过程。

⑤ 分步解答

  1. 接探头:两根导线(鳄鱼夹)分别接 micro:bit 的 P1(读数) 与 3V,线头做成两片不碰到的"电极"。
  2. 烧程序:读 P1 模拟值 → 映射成 LED 点阵亮度条 / 数字,边测边显示(可串口记录)。
  3. 归零:电极插入纯水,记下"零读数"。
  4. 定标:配 1 勺、2 勺、3 勺盐水(每杯水量一致),分别读数。
  5. 画浓度—读数曲线(柱状或折线)。
  6. 校准后测一杯未知盐水,在曲线上反查它的浓度。
  7. 记录卡:画曲线 + 写"我固定了什么、电极插多深、怎么归的零"。
