A · 本阶题离子导电 · 浓度建模 · 校准
1把探头插入下面三杯,读数最大的是?A 纯净水 / B 糖水 / C 盐水 本阶易可判分
思考方法:能导电的是水里"会动的离子";盐拆成离子,糖不拆成离子。 答:C
2同一杯盐水,不停加盐搅开,屏上读数会怎样变化?为什么? 本阶易人工判
思考方法:盐越多 → 离子越多 → 电越容易通过 → 读数越大。 参考:读数变大;盐越多离子越多,导电越强。
3为什么每次测之前要先把探头插进纯水"归零"、且电极要插同样深? 本阶中人工判
思考方法:仪器要"公平":不归零、插得深浅不同,数字就没法互相比——这就是校准 + 控制变量。 参考:归零去掉本底、固定插入深度,几杯读数才能放在一起比。
4你测了 1/2/3 勺盐水的读数并画成曲线。现在测一杯未知盐水,读数落在 2 勺和 3 勺之间,你怎么估它的浓度? 本阶中人工判
思考方法:在"浓度—读数"曲线上,用读数横着找到曲线、再竖下来读浓度——这就是用模型预测。 参考:在曲线上反查,浓度介于 2~3 勺之间、靠近哪端看读数更接近哪点。
B · 初中考点物质的导电性 · 溶液 · 电路
5下列能导电的是?A 干燥食盐晶体 / B 食盐水溶液 / C 蔗糖水 初中中可判分
思考方法:要有"能自由移动的带电粒子"才导电:干盐离子被固定不动、糖水无离子,只有盐水溶液有自由离子。 答:B
6盐水导电时,水里负责"搬运电"的是?A 水分子 / B 自由移动的离子 / C 糖分子 初中中可判分
思考方法:食盐在水中解离成带正、负电的离子,它们在电场里定向移动 = 电流。 答:B
7【实验探究】两杯盐水读数不同,小红说"一定是浓度不同"。可能还有哪些原因让读数不同?请至少说两条,并说怎么排除。 初中中人工判
思考方法:控制变量——除了浓度,水温、电极插入深度、电极间距、是否归零都会影响读数。 参考:温度、电极插入深度/间距、是否归零等都会影响;排除法是把这些全固定,只留浓度不同再比。
C · 高中考点电解质 · 离子浓度 · 电阻与导电
8下列属于电解质、且其水溶液能导电的是?A NaCl / B 蔗糖 / C 酒精 高中中可判分
思考方法:电解质在水中(或熔融时)能电离出自由离子;蔗糖、酒精是非电解质。 答:A
9同体积下,0.1 mol/L NaCl 与 0.1 mol/L 蔗糖溶液,导电能力怎样?从微观解释。 高中中人工判
思考方法:导电能力取决于自由离子浓度;NaCl 完全电离出 Na⁺、Cl⁻,蔗糖不电离、几乎无离子。 答:NaCl 溶液导电、蔗糖溶液基本不导电;因为 NaCl 电离出自由离子,蔗糖以分子形式存在、无自由离子。
10用我们的仪器读"导电强弱",其实读的是溶液电阻的反面。若读数 ∝ 电导(电阻的倒数),浓度升高时电阻怎样变、电导怎样变? 高中难人工判
思考方法:离子越多 → 电流越易通过 → 电阻越小 → 电导(=1/电阻)越大,读数越高。 答:浓度升高,离子增多,电阻减小、电导增大,读数升高(在稀溶液范围内近似单调)。
11【建模】测得读数 y 与盐勺数 x 近似满足 y = 40x + 10。某未知盐水读数为 130,估算它相当于几勺盐。 高中难可判分
思考方法:把模型反过来解:由 y=40x+10,代入 y=130 解 x。 答:130=40x+10 → x=(130−10)/40=3 勺。
