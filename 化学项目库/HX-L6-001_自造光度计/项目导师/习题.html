A · 本阶 / 挑战题自造仪器原理 · 标准曲线读取与反推
1用自造光度计测同一种有色溶液,浓的那杯透过的光强读数,比淡的那杯____(大/小)?为什么? 本阶易人工判
思考方法:颜色越深 → 光被吸收得越多 → 透出来到光敏的光越少 → 读数越低。 参考:小;浓的吸光多、透光少,光敏接收到的光弱,读数低。
2为什么要把 LED、比色杯、光敏电阻一起装进一个"遮光盒"里?不遮光会怎样? 本阶中人工判
思考方法:光敏只会"数"打到它身上的所有光,分不清是 LED 来的还是房间里来的。环境光混进来就读不准。 参考:遮光是为了让光敏只接收 LED 穿过样品的光;不遮光时环境光乱入,读数随房间明暗乱跳、无法横比。
3你配了 1×、2×、3× 三个已知浓度,测出读数并画成标准曲线。现在测一杯未知样,读数落在 2× 和 3× 对应读数之间。怎么估它的浓度? 本阶中人工判
思考方法:在标准曲线上,用未知样的读数横着找到曲线,再竖下来读浓度——这就是用模型反推。 参考:在曲线上反查,浓度介于 2×~3× 之间,读数更接近哪个点就更靠近哪个浓度。
4测之前,为什么要先放一个空比色杯(或装纯溶剂的杯)读一次,把它当"满光基准"? 挑战中人工判
思考方法:不同 LED 亮度、不同杯子的反光都会影响读数,先用"没有被染色"的状态定一个起点,后面的读数才有可比的基准——这就是校准/调零。 参考:用空杯/纯溶剂定"100% 透光"基准,扣掉杯子和 LED 本身的影响,后面各杯读数才能换算成相对透光、放在一条曲线上比。
5【立项设计】从开放清单里选"测饮料浓度排名"这个课题。请写出你的最简方案:测什么、用什么做标准曲线、怎么判断谁更浓。 挑战难人工判
思考方法:开放题答案不唯一,关键看四步齐不齐:对象 → 标定 → 测量 → 结论。比"贵不贵"更要比"读数说明了什么"。 参考要点:①取同一类有色饮料若干;②用同一饮料稀释成已知倍数系列做标准曲线;③统一比色杯、统一遮光,逐杯测透光读数;④读数越低=越浓,据此排名,并讨论误差。
B · 初中考点浓度与颜色 · 透光 · 控制变量
6同一种红墨水,A 杯滴 2 滴、B 杯滴 6 滴(水量相同)。哪杯颜色更深、透过的光更少? 初中易可判分
思考方法:同样多的水里,色素越多浓度越高、颜色越深,挡光越多。 答:B 杯更深、透光更少。
7小明在亮房间和暗房间分别用同一台自造光度计测同一杯水,读数不一样。最可能的原因是什么?怎么解决? 初中中人工判
思考方法:控制变量——除了样品本身,环境光是没被控制住的变量。要把它挡掉。 参考:环境光强弱不同被光敏一并读进去了;解决办法是把整个光路装进遮光盒,让光敏只接收 LED 的光。
8用光度计比较两杯有色水谁更浓,下列哪些必须保持一致才公平?①比色杯大小 ②光路对齐 ③LED 亮度 ④杯子放的位置 初中中人工判
思考方法:凡是会改变"光走多远、穿过多少液、被多少反射"的因素,都得固定,只留浓度一个变量。 参考:①②③④都要一致;否则光程、光强、对齐不同,读数差异就不只来自浓度了。
C · 高中考点朗伯-比尔定律 · 吸光度与透光率 · 线性范围
9朗伯-比尔定律 A = εbc。若比色皿厚度 b 和摩尔吸光系数 ε 不变,把浓度 c 变成原来的 2 倍,吸光度 A 怎样变? 高中中可判分
思考方法:A=εbc 中 A 与 c 成正比,ε、b 不变时 A 随 c 线性变化。 答:A 变成原来的 2 倍。
10透光率 T 与吸光度的关系是 A = −lg T。某溶液透光率 T = 0.01(即 1%),求它的吸光度 A。 高中难可判分
思考方法:把 T=0.01 代入 A=−lgT;lg(0.01)=−2。 答:A = −lg(0.01) = −(−2) = 2。
11某有色溶液测得 A=εbc 中 εb=0.50 L·mol⁻¹(此处 b 已并入)。今测得某未知样吸光度 A=0.30,求其浓度 c。并说明若读数落在曲线"弯掉"的高浓度段,为什么结果不可靠。 高中难人工判
思考方法:由 A=（εb)·c 反解 c=A/(εb);再想朗伯-比尔只在"线性范围"内成立,太浓时 A 与 c 不再成正比。 答:c = 0.30 / 0.50 = 0.60 mol/L。高浓度段偏离线性(标准曲线变弯),A 与 c 不再正比,直接反推会有较大误差;此时应稀释后再测。
A 段考"造仪器 + 读曲线 + 立项"的脚手架思维;B 段把"浓度—颜色—透光—控制变量"串成台阶;C 段从定性一路通到朗伯-比尔 A=εbc、A=−lgT 与线性范围,正是手册"看得见的建模"在最高阶的收顶。Q5/Q11 故意开放,考查方案设计与误差意识——L4 挑战者的关键。
