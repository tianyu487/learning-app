★点亮 KP

本阶 4 个 KP 从"比色法启蒙"走向"自造传感仪器 + 标准曲线校准 + 完整自主立项",掌握到"能造出仪器、能用标准曲线反推未知、能独立讲清原理与结论"。
认识KP1 比色法·吸光与浓度
朗伯-比尔启蒙:颜色越深、溶液越浓,光穿过去被吸收得越多、透出来的越少。
方法/电子KP2 自制传感仪器
LED 发出一束光,光敏电阻在对面接收透过的光强——自己造一只"会读光"的传感器。
方法KP3 标准曲线与校准
用几个已知浓度建一条"读数—浓度"标准曲线,再反推未知样的浓度。
方法KP4 完整自主探究立项
自选课题 → 设计 → 造 → 测 → 讲:L4 挑战者的完整闭环,科学方法主线收顶。
移入"上不封顶"、本阶不点亮:朗伯-比尔定律 A=εbc、吸光度 A 与透光率 T 的关系 A=−lgT、波长 / 滤光片选择、线性范围,留给学有余力者延伸(见习题进阶题)。

★开放命题脚手架

开放命题:自造一台光度计,当一回"浓度侦探"。
这一阶不给固定步骤,只给脚手架——从下面方向里自选一个,或自拟一个,然后自列 BOM、自定标准曲线、独立立项:
  • 方向 A · 饮料浓度排名:测不同果汁 / 饮料 / 茶水的颜色深浅,排出谁更浓,看看"贵的是不是更浓"。
  • 方向 B · 水质浊度:测一杯水的浑浊程度(透光越少越浑),对比自来水 / 河水 / 沉淀后的水。
  • 方向 C · 稀释倍数侦探:给一杯有色溶液,用仪器反推它被稀释了几倍。
  • 方向 D · 褪色进程跟踪:跟踪一个反应的褪色过程(如碘液或高锰酸钾被还原褪色),记录读数随时间变化。
要求:自选一个、自列 BOM、自定标准曲线,并说清"我测的是什么、怎么标定、误差从哪来"。

六件套 · 教学内容核

① 驱动问题

"颜色越深、透过的光越少——能不能自造一台仪器,用光的强弱'读出'一杯有色溶液到底有多浓?"

② 探究脉络(脚手架版)

1
好奇钩子KP1 预告
同一种有色水,越浓颜色越深。一束光从一头穿过去——淡的那杯对面还很亮,浓的那杯到对面几乎没光了。
反直觉:光"被喝掉了",3 秒抓注意力。
2
先动手试错KP1 缺口
先用肉眼比两杯有色水谁更深 → 两个人看法不一致、说不清差多少。"凭眼睛说不准,怎么给出一个客观的数?"
制造"需要客观读数"的缺口,逼出对仪器的需求。
3
玩中探究KP1KP2
自造光度计:遮光盒里 LED 对准光敏电阻,中间留一个比色杯槽。放杯子读透过的光强——越浓,读数越低。
在最想知道答案时,把比色法 + 自制传感器一起造出来。
4
回现实检验KP3KP4
用几个已知浓度做标准曲线;再测自选课题的未知样,在曲线上反推浓度;评估线性范围与误差。
用自造曲线预测未知,误差当裁判——现实说了算。
5
点亮+费曼全部
点亮 KP1–4;让孩子独立讲解仪器原理(光怎么被吸收、光敏怎么读)+ 课题结论,产出作品集条目(费曼 + 作品集)。
讲明白、能成集,才算 L4 挑战者达标。

③ 证据

类型内容
单调证据同一有色液,浓度越高,透过的光越少、读数越低 → 吸光随浓度单调变化。
标定证据用几个已知浓度建一条标准曲线,同一台仪器的读数才能换算成浓度。
预测证据用标准曲线反推未知样浓度,并与"应该的答案"(如已知稀释倍数)对照。
自主证据完整立项链:自选课题 → BOM → 造仪器 → 测 → 讲,留下作品集与立项模板。

④ 评价

  • 能说出:浓度越高,吸光越多 / 透光越少,读数越低。
  • 能自造仪器并解释光路:LED 发光 → 穿过比色杯 → 光敏接收,遮光为什么关键。
  • 能用标准曲线反推一杯未知样的浓度,并讨论误差与线性范围。
  • L4 挑战者达标:独立立项 → 交付 → 公开讲解(费曼),产出作品集条目。
  • 导师端三轴记录:点亮 KP 数 / 课题是否真由孩子自选自立 / 能否独立讲清仪器与结论。

⑤ 分步解答(项目流程脚手架)

  1. 选课题:从开放清单(饮料浓度 / 浊度 / 稀释倍数 / 褪色进程)里挑一个,或自拟一个,写下你要回答的问题。
  2. 列 BOM:列出要用到的材料(micro:bit、LED、光敏电阻、遮光盒、比色杯、标准液…),自己定清单。
  3. 搭光度计:在遮光盒内把 LED 对准光敏电阻,中间留出比色杯槽,固定光路、挡掉环境光。
  4. 烧程序:读光敏电阻的模拟值,显示成数字 / LED 条;放空杯或纯溶剂先定"满光"基准。
  5. 建标准曲线:配一组已知浓度系列,逐杯测读数,画成"读数—浓度"标准曲线。
  6. 测未知:测自选课题的未知样,在标准曲线上反推它的浓度。
  7. 写结论:写结论 + 误差讨论(遮光、比色杯、光路对齐)+ 作品集卡(含曲线、照片、一句话发现)。
