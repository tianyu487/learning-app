本盒为开放命题盒:不给固定步骤,给"造仪器的零件 + 立项脚手架"。附"课题方向清单 + 立项模板",学员自选课题、自列样品、自定标准曲线。
关键质控:遮光是最大误差源。① 环境光必须挡掉——光敏只该读 LED 穿过样品的光,漏光就读不准;② 比色杯规格一致——杯壁厚度、容量不同,光程就变,读数不可比;③ 光路对齐固定——LED、比色杯、光敏三点必须共线且每次位置一致。三者任何一条不达标,读数就不可横比、标准曲线就废。这是本盒成败点,务必在任务卡 + 盒体结构上保证遮光严、杯位准、光路固定。

2电子元器件清单

项说明
主控micro:bit ×1:读光敏电阻的模拟值,显示成数字 / LED 条。跨盒复用,沿用前几阶那块板。
LED单色发光元件(红 / 绿),作"光源";对准比色杯,光穿过样品后到光敏。
光敏电阻"接收器":透过的光越强、阻值越小,经分压由 micro:bit 模拟口读出。
限流电阻给 LED 限流、给光敏做分压;按预置电路连接。
预置程序附烧录好的 .hex / 扫码即烧版本,读光敏 + 显示;开放:鼓励学员自己改映射、加基准/阈值、做曲线记录。
同一块 micro:bit 从 L3 读电极、L5 集成系统,到本阶 L6 读光——务必在说明里强调"板子留好、接着用",支撑硬件一次购、耗材复购的模型。

3安全与履约

安全:仅用 micro:bit 低压(3V/USB)供电,严禁接市电;若课题选用高锰酸钾 / 碘液等需用低浓度且成人协助;实验液不入口、不入眼;LED 不直视(尤其亮色 LED);接线与首次烧录由成人协助。
项建议
分装micro:bit 防静电袋;LED / 光敏 / 电阻 / 杜邦线分格收纳;遮光盒、比色杯独立防压。
开箱即玩随盒附五拍脚手架卡 + 标准曲线卡 + 立项模板卡 + 课题方向清单 + 烧录指引,与导师/教研口径一致。
合规电子件 CE/RoHS;儿童用品安全标识;低压供电与"勿接市电、勿直视 LED、化学试剂成人协助"警示清晰。
